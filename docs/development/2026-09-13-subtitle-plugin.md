# 菜单、拖入预览和字幕插件第一阶段

- 顶部菜单互斥；点击外部或 Escape 关闭。拖入时间线时显示半透明落点预览，松手才提交。
- 独立插件 `plugins/moy-subtitles` 复用用户本地 MAW 源码的 SRT 解析/编码解码函数，保留 AGPL-3.0 LICENSE、NOTICE 和源码。没有修改上游工作区，也没有读取其 .env。
- 首次启动注册插件；现有工程通过“工作区 → 添加字幕页”选择加入，不自动改动用户页面组合。
- 输入 `workstation.timeline@1`；输出 `workstation.subtitles@1` 为 `{schema,timebase,cues:[{id,startTicks,endTicks,text}]}`。字幕通过信息发布保存到节点私有状态，支持 Core Undo。
- 回接剪辑页时在视频轨上方显示只读字幕轨和预览字幕，点击轨道头返回字幕页编辑。不回接时可直接接导出输入。图连接只声明信息关系，不启动自动化。
- 导出收集剪辑/导出输入连接的字幕并按来源去重，通过 GES title clip 烧录；超出视频时长的字幕截断，不因字幕意外延长成片。
- 字幕页支持 SRT、MAW .mosp/.json 导入、毫秒转换、时间偏移、文本/时间校对、发布及 SRT 导出。ASR 执行器、上游完整编辑器 UI、多语字幕样式与在剪辑页直接修剪字幕仍待接入，不能视为完整 MAW 移植。

验收：本轮按用户要求以编译为主，不运行大批测试。前端/Core/原生媒体编译结果与实际运行验证分开，界面、拖拽、字幕保存和成片需用户实测。
