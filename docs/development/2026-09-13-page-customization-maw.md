# 页面栏自定义与原版 MAW 编辑界面接入

纠正此前把页面装配做成顺序节点图、把 MAW 编辑器简化为表格的实现。

- 页面增删、拖动排序、模板保存统一放到底部“自定义”；信息图不再画装配顺序边，也不再提供页面排序箭头。
- 节点标题不再打开页面，标题区域直接拖动；放大接线圆点，过滤不兼容端口。重新接线可原子替换原输入；边可选择后 Delete/Backspace 删除。页面节点自身不会被 Delete 意外移除。
- 字幕插件接入上游原始 web 编辑器源码、预览播放器与字幕时间轴。宿主媒体 URL 流式接入原播放器，不再用简化表格替代原界面。
- 新增素材库输入；时间线连接提供可选时间线片段，素材库连接提供原始素材。宿主按 Asset ID 生成预览 URL，选中后实际调用上游加载媒体方法。
- “不触发自动执行”等内部说明移出 UI；接线仍只改变数据来源，不会偷偷调用模型。
- 完整上游源码、许可证与来源记录保留在插件目录。未修改用户克隆的原仓库、未读取 .env。

边界：ASR 执行器尚未接入。宿主 URL 预览不复制完整视频生成波形；原编辑器的手动本地文件加载仍保留波形生成路径。保存到工作站为显式操作。
验证按用户此前要求限于构建和脚本语法检查，不将编译通过描述为已经完成人工界面验收。
