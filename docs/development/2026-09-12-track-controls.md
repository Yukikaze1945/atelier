# 紧凑菜单与音视频基础轨道

- 标题区使用自绘紧凑菜单和原生窗口控制；移除工作区独立状态/显存栏及其资源轮询。菜单提供项目管理、撤销/重做、轨道添加、播放和工作区切换。
- 轨道头显示轨道编号、片段数、锁定、视频启用和音频 S/M。设置保存到项目并可撤销；锁定在 Core 拒绝编辑，禁用/静音/独听接到预览与 GES 导出。
- 新拖入视频通过原生 streams 元数据判断是否带音频，按 Vn/An 放入两个关联片段；没有音频流的视频不伪造音轨。旧工程已有片段不自动迁移。
- linkGroup 是片段的可选关联字段，不是渲染滤镜。关联片段一起移动、修剪参数、分割、恢复源时长和删除；覆盖余段分配独立关联组。视频部分只输出画面，关联音频片段输出声音，避免重复。
- 新增视频/音频轨道可用。尚未实现完整达芬奇工具集、真实音频波形或时间线连续缩略图条。

按用户要求，此轮仅编译，不运行回归测试；界面与实际剪辑行为交由用户验收。
