# 字幕页工程时间线与外观适配

- 去除外层素材下拉、加载和连接工具栏；连接信息改变后自动解析工程片段及 Asset ID，使用宿主流式媒体 URL。
- 不再加载上游 onboarding 脚本，隐藏对应教程入口；覆盖上游主题令牌为工作站中性灰黑与红色。
- 保留上游字幕校对功能，把“导入字幕 / 保存字幕”放回内部工具栏；独立工程新建/打开入口隐藏。
- 新增工程时间线媒体适配：以工程时间驱动字幕编辑器，按片段 start/in/duration 切换源、保留空隙、上轨视频优先、关联音频独立播放，遵守禁用、静音、独听。
- 字幕页显示实际工程音视频片段和字幕位置，可缩放、滚动及拖动播放头；字幕时间不再依赖手动源素材偏移。
- 当前这条预览路径为浏览器媒体适配，不是 GES/GPU 合成管线；没有新建伪造波形。真实音频峰值、复杂滤镜与变速仍未接入。

验证仅为脚本语法检查与构建，未声称实际播放器、多轨同步或界面已人工验收。
