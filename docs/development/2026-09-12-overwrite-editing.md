# 选中与同轨覆盖剪辑

## 对照与范围

在用户已打开的 DaVinci Resolve 剪辑页中只做单击选中观察：片段获得选中边框，播放头与监看画面停留在原来的 01:00:09:07。没有对该达芬奇工程移动、覆盖或删除素材。

本轮修复选中、同轨覆盖、取片和历史数据兼容，不声称已复刻达芬奇全部剪辑模式。插入/波纹剪辑、关联音视频编辑、修剪工具和转场仍须单独实现与验收。

## 规则

- 单击片段仅选中，不移动播放头；标尺点击负责定位。
- 同轨覆盖是区间替换而非隐藏叠放。新片段覆盖已有片段中部时，旧片段分成左右余段；右余段的源入点同步前移。
- 移动片段在原位置留下间隙，在目标位置执行同轨覆盖；不自动推动后面的片段。
- 删除覆盖片段后，原覆盖区间为空；仅撤销或显式恢复归档才找回被覆盖内容。
- 不同视频轨道仍为上下层关系，上轨优先；删除上轨片段后下轨可见是正确行为。
- 被覆盖区间作为独立片段归档，撤销恢复覆盖前完整快照。归档恢复也遵守同轨覆盖规则，避免再制造隐藏重叠。
- 旧项目的同轨重叠不在打开时偷偷迁移。检测到后显示“修复旧同轨重叠”，按旧画布后绘制片段优先进行一次可撤销整理。整理前点击命中与视频预览均优先选择后绘制片段。

## 回归

Core 测试覆盖头部/尾部/中间/完整覆盖、相邻无覆盖、源入点、删除与撤销、移动到另一轨道、上下轨保留、旧重叠显式整理以及归档恢复。

Electron 红蓝图像测试验证实际拖入同轨、播放跨覆盖边界、选中不跳片头、删除留空、撤销恢复，以及不同轨道的叠放。真实 MKV 测试增加跳转后单击选中不改变媒体时间的断言。

验收结果：构建通过，25 项 Core 测试、14 项单元测试通过；红蓝覆盖场景与项目/插件/保存重开桌面流程通过。真实 4K/120 fps MKV 首轮在播放前发生原生探测超时，单独重跑后完整通过（42.7 秒），包含跳转完成后单击片段仍保持源时间第 3 秒的断言。未为规避失败修改探测超时或降低播放断言。
