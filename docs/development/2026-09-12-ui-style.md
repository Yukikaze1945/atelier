# 默认 UI 参考图样式调整

用户要求按所提供的 DaVinci Resolve 截图调整初版 UI 的风格和色调。

- 主界面采用中性深灰、黑色监看区、灰色控件与细分隔线；主强调色为红色。
- 项目中心取消宣传大标题和渐变卡片，改为顶部标签/工具栏、媒体缩略图网格或紧凑列表、底部操作区。单击选中，双击、Enter 或“打开”进入工程。
- 项目封面尝试读取项目已有图片或视频；无法预览时显示灰色占位，不使用虚构的项目媒体。
- 剪辑页增加可切换的源/时间线双监看器、媒体池与检查器；媒体池点击素材名称载入源预览。
- 时间线背景改为灰阶；视频蓝色、音频绿色，播放头红色，片段选中边框浅灰。
- 基础控件、素材页、节点画布、插件市场与导出页同步采用中性灰调；外部插件自己的页面样式保持独立。
- Core、项目格式、插件 API、GES 与 GPU 执行代码未改动；Electron 仅调整窗口底色。
