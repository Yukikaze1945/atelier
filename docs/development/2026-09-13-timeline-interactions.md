# 时间线删除、磁吸、自动建轨与菜单

- Backspace、Delete、单独 X 删除选中片段并归档；输入框不拦截。Ctrl+C/X/V 为编辑器内复制/剪切/粘贴，剪贴板不跨项目。
- Shift+Backspace 波纹删除当前选中及其关联轨道片段，只将这些轨道的后续片段前移，不声称实现所有轨道的完整波纹模式。
- 片段首尾对播放头/其他片段边界吸附，播放头对片段边界吸附；13 像素阈值、黄色虚线提示、可点击磁吸开关。
- 向顶部空白建轨区拖动并释放，新建视频轨道；关联音频按对应编号创建/移动到音轨。音频下方留建轨区。移动及建轨在一个 Core 命令内可撤销。
- 片段菜单：复制、剪切、删除、关联轨道波纹删除、启用/禁用、分割、时长、名称、恢复源时长、关联选择开关、颜色和粘贴。
- 轨道菜单：添加、同类型内上下移、重命名、锁定、删除并归档、清理空轨、颜色、视频启用或音频静音/独听。
- Track 归档支持显式恢复；片段禁用接到预览和原生 GES 输出。未实现的 Fusion、字幕轨编辑、变速、环绕声布局和归一化未添加空菜单入口。

遵从用户要求：仅编译前端、Core 和媒体执行器，不运行测试；待用户实际验收。
