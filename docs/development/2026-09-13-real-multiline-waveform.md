# 恢复多行真实波形

- 撤掉字幕页内自建的音视频色块时间线，恢复 MAW 原有波形容器、基础/多行模式与字幕块交互；首次收到波形默认切至多行。
- 桌面 `media.waveform` 从当前工程解析启用的音轨，GStreamer 将源音频解码为 16 kHz 单声道浮点 PCM。按片段入点、位置、时长及静音/独听状态逐秒混合，再生成每秒 100 组真实 min/max 峰值。
- 关联音频不与视频内嵌声音重复计入；旧未拆音轨的视频按上轨遮挡关系选取可听区间。空隙保留真实静音。
- 峰值数据采用上游 `moy.asr.waveform.v1 / i8-minmax-base64` 契约。源文件大小/修改时间与时间线参与缓存键；临时 PCM 生成结束后清理，只保留小体积峰值缓存。
- 有生成中、失败及重试入口；旧请求结果不会覆盖新时间线。退出程序停止当前解码进程。

本轮仅脚本语法检查与构建，不声称已运行实际素材解码或完成 UI 验收。
