# ADR-0008：官方素材页分离硬盘浏览器与项目素材库

## 状态

已接受。

## 背景

用户希望官方自带素材页参考 DaVinci Resolve Media 页面的成熟工作流：上方或左上区域浏览硬盘、存储卷和文件夹，把需要的素材拖入下方的项目素材库；同时重新实现 Serpent 的高级资产浏览与组织能力，但不照抄其代码、数据库或产品结构。

硬盘中的文件与已经进入项目的素材不是同一种对象。前者只是外部源文件，可能移动、断开或被修改；后者需要稳定资产 ID、版本、来源、项目事务、归档和跨插件引用。如果把两者混成一个文件浏览器，时间线、插件产物和项目恢复会失去可靠主数据。

## 决定

预装的官方素材页插件采用两个明确分离但可以拖拽连接的区域：

1. **硬盘/来源浏览器（Source Browser / Media Storage）**：展示系统磁盘、移动存储、用户加入的位置和文件夹内容；负责发现、筛选、预览和选择外部文件，但浏览本身不创建项目资产。
2. **项目素材库（Project Media Library / Media Pool）**：展示已进入当前项目并由 Core 管理的资产、派生物和生成结果；负责 Bin、智能集合、元数据、版本、离线状态、归档以及发送到时间线和插件。

从来源浏览器拖入项目素材库是正式的 `ImportPlan`/导入事务，不是简单把文件路径塞给页面。导入成功后产生稳定 Asset ID；页面、时间线和插件都引用 Asset ID 与版本，而不是依赖原始绝对路径。

导入模式采用项目级可配置方案：每个项目保存“链接原文件”或“复制进项目”的默认值，单次拖拽允许临时切换而不改变项目默认值。创建或连接工作流模板时，素材页节点可以展开“高级选项”，在节点下方设置该项目的初始默认导入模式；模板应用后该值进入项目配置，项目中可以再次修改。项目内修改入口和具体交互暂不决定。

Serpent 只作为功能与交互参考。官方素材页独立重新实现所需行为并适配本项目的 React 页面、Rust Core、资产契约、GES/GStreamer 预览和插件信息连接；不直接移植 Serpent 应用、数据库、插件系统、MCP、Worker 或大段源码。

## 默认工作区骨架

```text
┌ 来源位置/磁盘树 ┬ 文件与文件夹画布 ┬ 源素材预览 ┬ 元数据 ┐
│ 驱动器/收藏位置 │ 网格/列表/搜索    │ 播放/波形   │ 检查器 │
├ 项目 Bin/智能集 ┴ 项目素材库画布    ┴────────────┴────────┤
│ Master / Bin / Smart / Shared   项目资产、生成物与派生物 │
└─────────────────────────────────────────────────────────┘
```

所有区域可折叠、调整大小并保存为工作区预设。布局参考 DaVinci Resolve Media 页面的信息结构与高密度暗色工作区，不复制其品牌资产、图标、代码或逐像素视觉。

## 数据边界

### 来源浏览器对象

- `SourceLocation`：磁盘、移动设备、NAS/用户位置或插件提供的来源。
- `SourceEntry`：尚未导入的文件、文件夹或识别到的图片序列。
- `SourceProbe`：格式、时长、分辨率、音轨、时间码和可预览状态等临时探测结果。

这些对象允许缓存，但不自动成为项目真相。

### 项目素材库对象

- `Asset`：稳定身份和当前内容版本。
- `AssetRevision`：原始、替换、重新生成或重新链接形成的版本。
- `Bin`：项目内手动组织层级，不等同磁盘目录。
- `SmartCollection`：保存的查询/过滤规则。
- `SharedCollection`：跨项目可重用素材入口，类似 Power Bin，但精确存储边界仍待设计。
- `DerivedArtifact`：缩略图、代理、波形、转码、分析或插件生成物。
- `SourceBinding`：资产与原始文件、外部 Provider 或生成任务之间的来源关系。

## 后果

### 正面

- 用户获得成熟的“找到硬盘素材 → 预览 → 拖入项目 → 整理和剪辑”流程。
- 外部路径变化不会直接破坏项目对象和插件引用。
- Serpent 的高级 DAM 体验可以围绕项目资产重新实现，而不是引入第二数据库。
- 来源位置和项目素材库都可以由插件扩展，例如云端素材、模型输出、游戏资产库或 Galgame 资源。

### 负面

- 导入需要明确链接、复制、重复、序列、离线和取消语义，不能只实现拖拽外观。
- 两块画布都需要虚拟化、预览和选择状态，UI 与缓存实现量较大。
- 跨项目共享素材若处理不当可能形成第三套“全局素材库”主数据，必须另行定义。

## 仍未决定

- 当素材页节点及项目都没有显式设置时，系统的后备默认值是链接还是复制。
- 项目内修改默认导入模式的入口、控件和提示方式。
- 单次拖拽临时切换导入模式采用修饰键、拖拽菜单还是确认面板。
- 文件夹拖入时是否默认保留磁盘层级为 Bin，以及递归规则。
- 跨项目 Shared Collection 保存真实资产副本、全局引用还是模板引用。
- 首批是否同时包含摄影现场所需的校验克隆/多目标备份工具。
