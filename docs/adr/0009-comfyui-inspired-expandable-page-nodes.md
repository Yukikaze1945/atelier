# ADR-0009：页面装配图采用 ComfyUI 式可展开节点

- 状态：已接受（首版页面节点交互）
- 日期：2026-09-01
- 范围：项目页面装配图

## 背景

页面装配图中的节点代表项目页面，作用是组合页面条并传递页面需要的信息。它不是 ComfyUI 式自动执行工作流；自动化仍由 Agent/MCP 或专门的自动化插件负责。

用户希望首版借鉴 ComfyUI 节点易识别、可折叠、可展开和端口清晰的特点，同时允许插件作者为页面节点添加自己的可选项，并能快速替换同类页面或同一插件包中的页面。

## 决定

### 1. 节点外观与展开

- 首版采用深色圆角卡片、标题栏、信息端口和折叠/展开区域组成的 ComfyUI 式节点骨架。
- 收起状态至少显示页面名称、插件标识、页面类型、主要端口和当前状态。
- 展开状态显示宿主通用选项、插件声明的可选项、依赖或错误状态。
- 插件自定义字段必须位于插件自己的命名空间，带稳定字段 ID 和 schema 版本；字段升级与迁移由插件声明。
- 只借鉴交互结构，不复制 ComfyUI 的商标、图标、代码、素材或逐像素视觉。

### 2. 页面预览按钮

- 节点左上角提供“页面预览”按钮。
- 鼠标悬停时临时显示该插件页面的样子；移出后临时预览关闭。
- 单击按钮固定展示预览；再次单击关闭固定展示。
- 键盘聚焦后使用 Enter 或 Space 执行同样的固定/关闭切换，并提供清晰焦点状态。
- 预览是静态截图、只读实时镜像还是受控页面实例，尚未决定，必须在 GPU、显存和插件隔离验证后选择。

### 3. 替换节点

- 节点右键菜单提供“替换节点”。
- 点击后打开小型替换选择页，固定分为两个标签页：
  - **同类型节点**：来自不同插件包、声明为同一页面类型的候选节点。
  - **同插件包节点**：由当前插件包提供的其他节点。
- 候选项至少显示名称、图标、插件包、节点类型、兼容状态和页面预览入口。
- 替换作为可预览、可撤销的项目装配事务提交。
- 默认保留页面条位置和画布位置；仅迁移兼容的公开配置与信息连接。
- 不得静默删除旧节点的插件私有配置、未匹配端口或页面状态。无法迁移的数据保存在替换记录或悬空占位中，以便撤销、恢复或人工重连。

## 状态模型

```text
收起 ⇄ 展开

悬停预览按钮 → 临时预览 → 移出关闭
                 └→ 单击固定 → 再次单击关闭

右键节点 → 替换节点 → [同类型节点 | 同插件包节点] → 兼容性确认 → 事务替换
```

以上状态都不执行媒体任务，也不代表自动化流程。

## 风险与约束

- 插件选项过多会让节点无限变高，因此后续需要定义分组、折叠和复杂编辑器跳转规则。
- 实时页面预览可能占用 GPU/显存，不能默认启动插件模型或完整渲染管线。
- “同类型”只表示候选范围，不等于端口和配置必然兼容；替换前必须计算并展示兼容性。
- 页面节点、信息节点和自动化节点必须有可辨识的视觉语义，避免用户误以为页面连线会执行任务。

## 尚未决定

1. 页面预览采用静态截图、只读实时镜像还是受控页面实例。
2. 悬停延迟、预览尺寸、定位方式，以及是否允许同时固定多个预览。
3. 插件选项只允许 schema 控件，还是允许受控自定义 UI。
4. 替换选择页是否提供搜索、收藏、排序和未安装市场候选。
5. 页面类型分类法、兼容性评分和版本迁移协议。
6. 未匹配端口的具体重连界面。
