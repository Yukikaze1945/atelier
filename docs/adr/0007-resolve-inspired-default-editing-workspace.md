# ADR-0007：默认剪辑工作区参考 DaVinci Resolve Edit 页面

## 状态

已接受为官方基础剪辑插件的初始交互方向。

## 背景

本项目希望成为面向 AI 创作和开放插件的次世代剪辑工作站，但第一版仍需要让有剪辑经验的用户立即理解素材、监看器、时间线、检查器和页面导航。DaVinci Resolve 的 Edit 页面已经形成成熟的传统 NLE 工作区结构：素材浏览、源/时间线监看器、轨道时间线和 Inspector 共同工作。

本项目同时要求页面可由插件装配，官方基础剪辑插件也不是 Core 中不可替换的固定页面。因此只能借鉴成熟的交互骨架，不能让整个宿主壳或所有插件页面都服从一套固定布局。

## 决定

官方基础剪辑插件的初始默认工作区参考 DaVinci Resolve Edit 页面的成熟布局与交互习惯：

- 项目页面条保持横向、直接进入页面的导航方式。
- 剪辑页默认提供可折叠/可调整的素材池或媒体浏览区。
- 中央提供源素材与时间线预览，可在空间不足时切换单监看器布局。
- 下方是多轨时间线和紧邻时间线的编辑工具。
- 右侧是随当前选择变化的 Inspector/属性区。
- 面板可以隐藏、调整大小并保存为项目或用户工作区预设。

“参考”只覆盖信息架构、专业编辑习惯和高密度工作区原则，不复制 Blackmagic 的商标、图标、素材、代码、精确尺寸或逐像素视觉。颜色、设计令牌、图标语言、插件插槽和产品品牌由本项目自行设计。

## 插件边界

- 该布局属于预装的官方基础剪辑插件，不是所有页面插件的强制模板。
- 宿主只提供页面容器、页面条、全局状态区和标准可选面板插槽。
- 第三方剪辑插件可以采用不同布局；字幕、LLM、TTS、Galgame 等页面也不需要伪装成传统剪辑页。
- 素材区、Inspector、工具栏和查看器覆盖层可以成为贡献位置，但同一区域的排序、折叠和冲突由宿主组合规则处理。
- GES/GStreamer 不进入 UI 组件；界面只调用官方剪辑插件公开的时间线和媒体适配接口。

## 结果

### 正面

- 降低传统剪辑用户的学习成本。
- 为素材、预览、时间线和属性建立清楚的初始位置。
- 保留页面插件和替代剪辑插件的布局自由。
- 可以把 AI 生成、字幕、滤镜和 Agent 能力逐步放入熟悉的编辑上下文，而不是先发明一套完全陌生的操作方式。

### 负面

- 高密度布局对小屏幕、缩放和 Electron 原生预览嵌入要求较高。
- 如果只模仿外观而没有专业剪辑行为，会形成“像达芬奇但不好用”的反效果。
- 插件贡献过多时，素材区、Inspector 和工具栏可能拥挤，需要明确组合规则。

## 验证门槛

1. 1080p、1440p、4K 和 125%/150% Windows 缩放下均可使用。
2. 单/双监看器切换不丢播放位置和选择状态。
3. 时间线、素材区与 Inspector 调整大小时，GPU 预览不闪烁、不回读 CPU。
4. 至少安装两个向同一区域贡献 UI 的插件，验证排序、折叠和冲突提示。
5. 工作区预设只能保存布局，不得复制或分叉项目时间线数据。
