# 官方素材页完整功能规划

> 日期：2026-09-01  
> 状态：硬盘来源浏览器 + 项目素材库的双区结构、独立复刻原则、项目级可配置导入模式及语义素材搜索方向均已确认。项目内修改入口、无配置时的后备默认值和语义索引细节仍待决定。本文只做产品与架构规划，不代表开始实现。

## 1. 产品定位

素材页不是普通的“打开文件”对话框，也不是独立于项目的第二套 DAM。它是整个工作站的资产入口：从硬盘和插件来源发现内容，将其正式纳入项目，建立稳定资产身份，然后供时间线、生成页、字幕页、音频页、Agent/MCP 和导出页共同使用。

视觉和主要流程参考 DaVinci Resolve Media 页面；高级浏览和整理能力参考 Serpent，但独立重新实现并适配本项目。

## 2. 页面区域

### 2.1 来源位置树

- 展示本地磁盘、容量/使用率、移动设备、网络位置和用户收藏位置。
- 展开文件夹树，支持前进、后退、上级、面包屑、最近位置和路径输入。
- 插件可以贡献新的 `SourceProvider`，例如对象存储、云盘、素材站或游戏资源库。
- 断开的磁盘或网络位置保留入口和状态，不伪装为空目录。

### 2.2 硬盘文件画布

- 文件夹、视频、音频、图片、字幕、文本、工程交换文件、3D 和图片序列使用不同类型呈现。
- 网格、列表、瀑布流/自适应画布、缩略图大小调整。
- 搜索、格式过滤、日期/大小/时长/分辨率排序和隐藏文件开关。
- 悬停预览、快速 scrub、音频波形、图片序列播放和元数据摘要。
- 多选、框选、键盘导航、拖拽文件或整个文件夹进入目标 Bin。
- 在导入前允许打开源预览并设置 In/Out，候选支持创建只引用范围的 Subclip。

### 2.3 源素材预览

- 视频/音频播放、逐帧、快速 seek、In/Out、声道和时间码查看。
- 图片缩放、透明背景、色彩空间/曝光预览；专业格式由格式插件扩展。
- 预览使用 GES/GStreamer/格式插件提供的统一 PreviewHandle，不由 React 页面自行运行另一套 FFmpeg 管线。

### 2.4 元数据 Inspector

- 来源文件只读技术信息与可预览信息。
- 进入项目后的自定义标题、说明、标签、评分、颜色、镜头/场景/Take、作者、版权、语言和插件字段。
- 文件级、帧级、音轨级和项目自定义元数据分组展示。
- 多选时支持公共字段批量修改，并明确显示混合值。

### 2.5 项目 Bin/集合树

- Master、层级 Bin、智能集合、跨项目共享集合和归档入口。
- Bin 是项目组织关系，不强制映射磁盘目录。
- Smart Collection 保存查询规则并随资产和元数据变化自动更新。
- 生成物、待审阅、离线、缺少插件、代理未就绪等系统集合由查询生成，不复制资产。

### 2.6 项目素材库画布

- 复刻 Serpent 的高性能虚拟化浏览体验：平铺、列表、瀑布流、自适应布局、缩放、滚动锚点和大库浏览。
- 缩略图、悬停预览、视频 scrub、音频波形、图片序列、3D/PDF/RAW 等查看能力。
- 搜索表达式、字段过滤、排除条件、排序、标签、评分、喜欢、颜色、描述和智能集合。
- 显示原始/生成/派生/代理/离线/归档/插件缺失等来源和状态徽标。
- 资产可以拖到时间线、发送给页面/插件、建立信息连接或作为模型输入；所有动作引用 Asset ID 和 Revision。

## 3. 从硬盘拖入素材库的数据流

```text
用户拖拽 SourceEntry/文件夹
            ↓
建立 ImportPlan（目标 Bin、模式、递归、序列、重复处理）
            ↓
探测格式/元数据/磁盘空间/可用插件
            ↓
用户确认尚未默认化的冲突
            ↓
Core 提交导入事务并分配 Asset ID
            ↓
后台生成缩略图、波形、代理和索引
            ↓
素材库立即显示资产；派生物随后渐进就绪
```

拖入多个文件或文件夹时，导入会形成一个可追踪的 Import Session。取消、失败和重试不能留下无法识别的半套资产；已经完成的文件操作与项目事务需要有明确恢复记录。

## 4. 对齐 DaVinci 的成熟能力

Blackmagic 官方把 Media 页定义为导入、组织、同步和添加元数据的专用工作区，并明确采用“上方硬盘、下方当前项目 Media Pool、拖拽导入”的结构。完整规划保留以下能力类别：

- 普通 Bin、Smart Bin 和跨项目可重用集合；
- 图标/列表等视图、搜索与自定义显示；
- 音频和视频按时间码、波形或手动方式同步；
- 文件级和帧级元数据、可编辑字段和自定义元数据视图；
- 源端 LUT/解释、音轨和帧率等非破坏属性；
- 相机卡/目录的校验克隆与多目标备份能力；
- 文件夹及子目录导入、可选保留层级为 Bin；
- 导入前预览和候选 Subclip 创建。

这些是完整产品能力清单，不表示必须在同一交付批次完成，也不等于照抄 Blackmagic 的菜单和对象名称。

来源：[DaVinci Resolve Media](https://www.blackmagicdesign.com/products/davinciresolve/media)、[DaVinci Resolve Edit](https://www.blackmagicdesign.com/products/davinciresolve/edit)。

## 5. 超过 DaVinci 的项目特性

- AI/插件生成内容直接作为有来源、有版本的项目资产返回素材库。
- 资产可以向插件暴露有类型的信息端口，但连接本身不自动执行任务。
- Agent 通过 MCP 搜索、导入、整理、预览和发送资产，复用同一 Host 操作。
- 素材卡显示显存相关的代理/模型状态，但素材页本身不占用不必要的模型显存。
- 不需要的资产进入项目归档并可恢复；原始文件是否移动或删除必须是独立、明确的文件操作。
- 插件可扩展来源、预览器、元数据字段、Inspector 区域、菜单、缩略图生成器和资产处理操作。

### 5.1 语义素材搜索（长期方向）

- 素材页后续支持以 WeMM-Embedding-2B 这类 Embedding 模型为项目素材建立语义索引，使用户能够用自然语言查找画面、音频、文本和其他可描述素材。
- WeMM-Embedding-2B 是当前代表模型，不写死为 Core 唯一实现；Embedding 生成器和索引后端应可由插件或 Provider 替换。
- 素材页的人类搜索与 Agent 搜索复用同一套资产搜索契约、过滤条件和稳定 Asset ID/Revision 返回值，避免形成两套结果语义。
- Agent 可以通过 MCP 直接发起语义素材搜索并取得结构化候选，不需要模拟操作素材页 UI。
- 语义搜索只负责检索和返回素材信息；是否把素材放入时间线、发送到插件或启动处理，仍由用户操作或 Agent 的显式后续调用决定。

## 6. 非功能要求

- 10 万级资产仍能连续滚动和筛选，画布不能一次创建全部 DOM。
- 大目录扫描、缩略图、波形和代理生成不阻塞 UI。
- 硬盘拔出、NAS 断线、格式插件崩溃和源文件变化都有可恢复状态。
- 浏览外部目录不能静默修改、移动或建立项目对象。
- 从导入到时间线和插件的资产引用必须跨平台、可迁移，不能只保存 Windows 盘符路径。
- 相同源文件的重复导入、重新链接和内容变化必须可解释，不靠文件名猜测身份。

## 7. 已确认的导入模式配置

用户已经选择方案 C：

- 每个项目保存一个默认导入模式：`link`（链接原文件）或 `copy`（复制进项目）。
- 单次拖拽可以临时使用另一种模式，但不修改项目默认值。
- 在创建/连接工作流模板时，展开素材页节点下方的“高级选项”，可以为使用该节点的项目选择初始默认导入模式。
- 模板应用后，该值进入当前项目配置；项目以后可以修改，不要求永远跟随模板。
- 工作流模板仍只负责页面、插件和基础配置装配，这项设置不会自动导入或移动任何素材。

```text
素材页节点
├─ 页面/插件基本信息
└─ 高级选项（展开）
   └─ 默认导入方式：链接原文件 / 复制进项目
```

## 8. 继续保留未定的部分

- 项目内从哪里修改默认导入模式，以及使用设置页、素材页工具栏还是其他入口。
- 单次拖拽临时切换采用修饰键、拖拽菜单还是导入确认面板。
- 模板和项目均未设置时采用哪个后备默认值。
- 模板升级时如果项目已经本地修改该值，差异界面如何呈现；仍遵守“用户查看差异后主动升级”的既有原则。
- 语义索引按完整资产、镜头/时间段还是多层粒度建立，以及不同媒体类型采用哪些描述与 Embedding。
- Embedding Provider 契约、向量索引存储位置、增量更新、模型切换后的重建策略和离线资产处理方式。
- 索引任务如何调度 GPU/显存，以及它与本地 LLM、视频生成等模型的显存释放机制如何协作。
