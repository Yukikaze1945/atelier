# 页面节点交互设计记录

- 状态：核心交互已确认；实现细节待验证
- 日期：2026-09-01
- 对象：项目页面装配图中的页面节点
- 关联：`docs/adr/0009-comfyui-inspired-expandable-page-nodes.md`

## 1. 节点语义

页面节点保存页面身份、页面条顺序、插件版本、页面配置、信息端口、状态和预览入口。点击节点进入对应页面；连接页面节点只表达页面装配或已定义的信息关系，不执行任务。

自动流程不属于这里。需要自动化时，由 Agent 通过 MCP 或专门的自动化插件读取这些信息并调用能力。

## 2. 首版结构

```text
┌──────────────────────────────────────────┐
│ [展开] [页面预览]  页面名称       状态/菜单 │
│ 插件图标  插件包名  页面类型              │
├──────────────────────────────────────────┤
│ 输入信息端口                    输出信息端口 │
├────────────── 展开后出现 ────────────────┤
│ 宿主通用选项                              │
│ 插件声明的可选项                          │
│ 依赖、错误或迁移提示                       │
├──────────────────────────────────────────┤
│ 版本 / 本地覆盖状态 / 来源                 │
└──────────────────────────────────────────┘
```

节点需要覆盖以下可见状态：默认、悬停、选中、键盘焦点、收起、展开、正常、禁用、插件缺失、不兼容、需要迁移、存在项目本地覆盖、临时预览、固定预览。错误和兼容状态不能只靠颜色表达。

## 3. 插件作者可添加的选项

插件可以为展开区声明可选项。每个字段至少需要：

- 稳定字段 ID、显示名和说明。
- 数据类型、默认值与验证规则。
- 是否随工作流模板保存。
- 是否允许项目本地覆盖。
- schema 版本与迁移方式。

首版可优先覆盖开关、枚举、数字、文本、路径、资源引用、页面引用和信息端口映射。是否允许插件注入任意自定义 UI 暂不决定；这会影响布局冲突、主题一致性、状态持久化和崩溃隔离。

## 4. 页面预览

### 4.1 已确认行为

- 左上角按钮悬停：打开临时预览；鼠标离开后关闭。
- 单击：把预览固定展示。
- 再次单击：关闭固定展示。
- 键盘聚焦后 Enter/Space：执行相同切换。

临时预览不改变当前项目页面、不写入工程、不启动模型任务。固定预览只是方便对照页面样式，不等于进入该页面。

### 4.2 实现候选，暂不选择

| 方案 | 优点 | 主要风险 |
|---|---|---|
| 静态截图/插件提供封面 | 最轻、最稳定、不会占用模型显存 | 无法反映项目当前状态 |
| 只读实时镜像 | 能看到真实布局和项目上下文 | 需要定义刷新、GPU 占用和交互隔离 |
| 受控页面实例 | 最接近真实页面 | 成本最高，可能重复加载模型、媒体管线和插件状态 |

Esc 是否关闭固定预览、是否允许同时固定多个预览、预览尺寸和出现位置仍待设计。

## 5. 替换节点

### 5.1 操作路径

```text
右键节点
  → 替换节点
  → 小型选择页
      ├─ 同类型节点
      └─ 同插件包节点
  → 选择候选
  → 查看兼容状态和变更摘要
  → 确认替换
```

“同类型节点”用于跨插件寻找相同页面类型；“同插件包节点”用于在一个插件作者提供的页面集合中切换。后者可能包含不同类型，因此仍然需要显示兼容状态。

### 5.2 替换事务

替换默认保留：

- 页面条位置。
- 节点画布位置与折叠状态。
- 两端都声明兼容的公共配置。
- 类型和版本兼容的信息连接。
- 旧节点完整状态的恢复记录。
- 一次 Undo 恢复替换前状态的能力。

替换不得静默丢弃：

- 插件私有配置。
- 没有对应项的端口连接。
- 页面局部状态。
- 插件缺失时仍可恢复的数据。

未安装候选是否可以从替换页跳转市场安装，暂不决定。

## 6. 失败与恢复

- 插件 schema 无法加载：显示缺失/错误占位，保留原始数据。
- 页面预览失败：只关闭预览并显示错误，不影响节点和项目。
- 配置迁移失败：中止事务，原节点保持不变。
- 端口无法匹配：展示差异，不自动删除连接。
- 插件崩溃：宿主保留页面节点和恢复信息。
- 插件卸载：节点变成可恢复的缺失插件占位，不从项目中消失。

## 7. 首版验收口径

- 鼠标和键盘均可完成展开、预览固定/关闭和替换。
- 插件声明的字段能够显示、验证、保存并随项目恢复。
- 替换页准确显示“同类型节点”和“同插件包节点”两个标签。
- 兼容配置与连接能够迁移；不兼容项在确认前可见。
- 一次 Undo 能完整恢复旧节点、位置、配置和连接。
- 悬停预览不会启动媒体任务、模型任务或隐式占用大量显存。
- 插件缺失或崩溃后，项目仍能打开并保留占位节点。
- 页面装配、信息连接和 Agent 自动化三种语义在视觉与文案上可以区分。
